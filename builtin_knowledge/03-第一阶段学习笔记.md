## ① LLM / 大语言模型 🤖

### 一句话
> AI的"大脑"。相当于你雇了一个**什么都知道一点但需要你指挥的博士生**。

### 全称
**Large Language Model**（大语言模型）

### 它是怎么来的？
它读了**整个互联网**上的文字（书籍、文章、网页、代码），学会了"人类是怎么说话的"。但它不是"真的理解"，它是**根据概率猜下一个字最该说什么**。

### 常见的大模型

| 模型 | 公司 | 特点 |
|:---|:---|:---|
| GPT-4 | OpenAI | 最成熟，生态最完善 |
| Claude | Anthropic | 200K超长上下文，代码强 |
| Gemini | Google | 多模态能力强 |
| DeepSeek | 深度求索 | 便宜，中文好 |
| 通义千问 | 阿里云 | 中文好，国内可用 |

### 打个比方 🎯
> LLM就像一个**读完了全世界所有书的图书管理员**。你问它问题，它从读过的内容里组合出最合理的回答。但它没读过的书（没见过的新知识），它就不知道。

### 工作中的用途
```
✅ 写邮件、写报告、写文案
✅ 总结长篇文档
✅ 回答基于知识的问题
✅ 生成代码
✅ 翻译
```

## ② Token 🪙

### 一句话
> AI计算文字的**计量单位**。就像去超市按"斤"算，AI按"Token"算。

### 不同语言的Token换算

| 语言 | 1个Token大约 |
|:---|:---:|
| 英文 | 1个单词 ≈ 1个Token |
| 中文 | 1个汉字 ≈ 2个Token |
| 代码 | 1个符号 ≈ 1个Token |

### Token的两个重要意义

**① 计费：** API调用按Token收费
```
DeepSeek：输入 约0.5元/百万Token，输出 约2元/百万Token
Claude：  输入 约3元/百万Token，输出 约15元/百万Token
```

**② 限制：** 模型有"最大Token限制"
```
GPT-4：  128K Token（约10万汉字）
Claude： 200K Token（约15万汉字，相当于整本《三体》）
```

### 💡 记着玩
> **你输入的话 + AI输出的话，都按Token算钱。字越多，Token越多。**

## ③ 上下文窗口 📏

### 一句话
> AI的"短期记忆容量"。一次能记住多少内容，决定AI能不能"记得"你之前说了什么。

### 详细理解
- 上下文窗口 = AI一次对话能"看到"的最大内容量
- 窗口内的内容AI都能"记住"
- 超出窗口的内容AI就"忘了"（跟人一样，短期记忆有限）

### 不同模型的"记忆力"对比

| 模型 | 上下文窗口 | 相当于 |
|:---|:---:|:---|
| GPT-4 | 128K | 一本《三体》|
| **Claude** | **200K** | **一本半《三体》** |
| Gemini | 1M（百万级） | 几十本书 |

### 工作中的实际意义

| 场景 | 上下文窗口的影响 |
|:---|:---|
| 分析一整份合同 | 窗口够大 → 一次搞定 |
| 连续对话10轮 | 窗口够大 → AI记得之前聊的 |
| 上传PDF分析 | 窗口够大 → 不用切文档 |
| 长篇代码审查 | 窗口够大 → AI能看完整段代码 |

## ① Prompt / 提示词 📝

### 一句话
> **你跟AI说的话，就是Prompt。** 你问什么、怎么问，决定了AI给你什么答案。

### 好Prompt的万能公式 🏆

```
角色 + 任务 + 背景 + 要求 + 输出格式
```

| 要素 | 说明 | 例子 |
|:---|:---|:---|
| **角色** 👤 | AI扮演谁 | "你是一个资深HR" |
| **任务** 🎯 | 具体要干什么 | "帮我写一份面试邀请邮件" |
| **背景** 📋 | 补充信息 | "候选人是高级前端工程师" |
| **要求** 📏 | 约束条件 | "字数不超过300字，语气专业" |
| **输出格式** 🎨 | 要什么样式 | "用Markdown格式，分三段" |

### 好Prompt vs 差Prompt 对比

```
❌ 差Prompt：
"帮我写个东西"

✅ 好Prompt：
"我是一家电商公司的运营，需要写一条推广夏季防晒霜的朋友圈文案。
要求：200字以内，语气轻松活泼，带2-3个表情符号，
突出'清爽不油腻'这个卖点。目标人群是20-30岁女性。"
```

### 工作中常用Prompt模板

**① 总结类：**
```
你是一个[角色]。
请帮我总结以下内容，要求：
- 提炼3-5个核心要点
- 每个要点用一句话概括
- 用项目符号列出

内容：[粘贴内容]
```

**② 改写类：**
```
请帮我改写这段文字，要求：
- 语气更[专业/轻松/正式]
- 缩短到原来的一半
- 保留所有关键信息

原文：[粘贴内容]
```

**③ 头脑风暴类：**
```
我需要[想10个]关于[主题]的[创意/方案]。
要求：
- 每个方案说明优缺点
- 有可行性评估
- 按优先级排序
```

### 💡 小技巧
> 用同一个问题，换3种不同的Prompt去问AI，你会得到3个完全不同的回答质量。这就是Prompt的魔力 ✨

## ② Temperature / 温度 🌡️

### 一句话
> **控制AI"发散程度"的旋钮。** 温度越低，AI越保守；温度越高，AI越有"创意"。

### 温度值对照表

| 温度值 | AI的状态 | 像什么 | 适合场景 |
|:---:|:---|:---|:---:|
| **0 - 0.3** 🧊 | 保守、严谨、每次都差不多 | 照本宣科的老师 | 翻译、代码、事实问答 |
| **0.5 - 0.7** 🌤️ | 平衡、自然 | 正常的聊天 | 日常对话、写作 |
| **0.8 - 1.0** 🔥 | 创意、发散、每次都不一样 | 天马行空的艺术家 | 写诗、脑暴、创意文案 |

### 实际感受

同样的问题，Temperature 0 和 Temperature 1 的回答天差地别：

| 温度0 🧊 | 温度1 🔥 |
|:---|:---|
| 去公园散步 | 去废弃工厂拍赛博朋克照片，然后去天台吃火锅！ |
| 稳定、合理、安全 | 有趣、随机、可能离谱 |

### 工作中怎么设

```
写代码       → Temperature 0.1-0.2（要精确，别乱编）
写邮件       → Temperature 0.3-0.5（规范但自然）
写文案       → Temperature 0.7-0.8（需要创意）
写诗/小说    → Temperature 0.9-1.0（越放飞越好）
```

### 💡 一句话记住
> **Temperature越低越"听话"，越高越"有想法"。干活用低温，创意用高温。**

### 注意
> 网页版（ChatGPT/Claude网页）**没有这个选项**，这是API才有的参数。网页版是服务商帮你设好了默认值。

## ③ API 🔌

### 一句话
> **让程序能用AI的"接口"。** 就像插座——你不需要自己发电，插上就能用电。

### 网页版 vs API 的区别

```
网页版AI（ChatGPT/Claude网页） = 聊天界面 + 背后的大模型（一体化）
API调用                        = 只有背后的大模型（没有聊天界面）
```

### 一个场景让你秒懂

```
❌ 没有API：
你每天手动把100条客户评价复制到ChatGPT让AI分析
每条花2分钟，100条 = 3个多小时

✅ 有API：
写个程序，自动读取100条评价 → 批量发给AI → 自动出分析报告
全部自动化，5分钟搞定
```

### 我的第一个API调用（已跑通 ✅）

**文件位置：** `D:\Desktop\电信\test_api.py`

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://api.*******.vip/v1"  # ← 注意要加 /v1！
)

response = client.chat.completions.create(
    model="deepseek-v4-flash-free",  # 模型名不一定是 deepseek-chat
    messages=[
        {"role": "user", "content": "你好！请用一句话介绍你自己"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
```
